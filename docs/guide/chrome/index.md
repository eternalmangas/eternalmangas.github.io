# Chrome Extension

The EternalMangas Chrome extension lets you browse manga and comics directly from your desktop browser.

## Download

**[Download Chrome Extension v0.2.0](https://github.com/eternalmangas/eternalmangas.github.io/releases/download/v0.2.0/eternalmangas-chrome-extension.zip)**

Browse all releases: [GitHub Releases](https://github.com/eternalmangas/eternalmangas.github.io/releases)

## Installation

1. Download the ZIP file linked above.
2. Extract/unzip the file to a folder on your computer.
3. Open Google Chrome and navigate to `chrome://extensions`.
4. Enable **Developer mode** (toggle in the top-right corner).
5. Click **Load unpacked**.
6. Select the unzipped folder containing the extension files.
7. The EternalMangas extension is now installed.

## Setup

That's it — **zero configuration required**.

The extension comes with a default API server pre-configured. After installation:

1. Click the EternalMangas extension icon in your Chrome toolbar.
2. Browse, search, and read from over **2900+ series**.

:::info
You can optionally change the API server. See [Extension Configuration](/guide/mihon/configuration) for available API servers.
:::

## Updating

To update the extension:

1. Download the latest version from the link above.
2. Extract it to the same folder (or a new folder).
3. Go to `chrome://extensions` and click the **reload** button on the EternalMangas extension card, or remove and re-load it.

## Troubleshooting

### Extension not loading

- Make sure Developer mode is enabled in `chrome://extensions`.
- Verify you selected the correct folder (the one containing `manifest.json`).

### No content loading

- Check your internet connection.
- Verify the API URL in the extension settings (see [Extension Configuration](/guide/mihon/configuration)).
