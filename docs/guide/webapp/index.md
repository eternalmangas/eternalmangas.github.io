# Web App

The EternalMangas web app lets you browse manga and comics directly from your desktop browser — no extension installation required.

## Access

**[Open the Web App](https://mangapdf.org)**

Browse all releases: [GitHub Releases](https://github.com/eternalmangas/eternalmangas.github.io/releases)

## Getting Started

1. Open [mangapdf.org](https://mangapdf.org) in your browser.
2. Browse, search, and read from over **2900+ series**.
3. That's it — **zero configuration required**.

:::info
You can optionally change the API server. See [Extension Configuration](/guide/mihon/configuration) for available API servers.
:::

## Troubleshooting

### No content loading

- Check your internet connection.
- Verify the API URL in the settings (see [Extension Configuration](/guide/mihon/configuration)).

### Still having issues?

Open an issue on [GitHub](https://github.com/eternalmangas/eternalmangas.github.io/issues) with details about your problem.
